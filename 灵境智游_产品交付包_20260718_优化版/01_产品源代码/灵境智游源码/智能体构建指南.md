## 什么是智能体

**智能体（Agent）** 是在大语言模型（LLM）基础上，增加了以下能力的 AI 系统：

```
智能体 = 大语言模型 + 人设提示词 + 知识库 + 工具调用 + 记忆
```

与传统对话系统的区别：

| 特性 | 传统问答 | 智能体 |
|------|----------|--------|
| 理解能力 | 关键词匹配 | 语义理解 |
| 知识范围 | 固定条目 | 动态检索 + 模型知识 |
| 工具使用 | 不支持 | 可调用外部工具 |
| 上下文 | 无记忆 | 多轮对话记忆 |
| 人设 | 固定模板 | 鲜明的角色人设 |
| 扩展性 | 需硬编码 | 可通过配置扩展 |

## 为什么需要智能体

### 本项目中的升级

在灵境智游中，我们将数字人对话从**关键词匹配的本地知识库**升级为**智能体驱动的智能对话**：

**升级前（本地知识库模式）：**
- 用户在 `AssistantPanel.jsx` 输入问题
- `resolveAnswer()` 函数按关键词在 8 条预设问答中匹配
- 返回固定答案

**升级后（智能体模式）：**
- 用户输入问题
- `callAgent()` 调用通义千问智能体 API
- 智能体结合人设、知识库、上下文生成回答
- 支持工具调用（天气查询、路线推荐等）

### 核心优势

1. **更自然的对话体验**：不再局限于预设问题，能理解各种自然语言提问
2. **更丰富的人设表达**：每位数字人有独特的说话风格和性格
3. **可扩展的知识能力**：通过 RAG 接入更多景区文档
4. **动态工具调用**：可实时查天气、推荐路线、查询演出时间

## 构建智能体的完整步骤

### 方式一：阿里云百炼平台（推荐）

阿里云百炼平台提供可视化的智能体创建和管理界面。

#### 步骤 1：创建智能体应用

1. 登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)
2. 进入「我的应用」→「创建应用」
3. 选择「智能体应用」模板
4. 填写基本信息：
   - **应用名称**：灵境智游 · 灵若
   - **应用描述**：灵山胜境人文讲解数字人
   - **基础模型**：通义千问 Plus（qwen-plus）

#### 步骤 2：配置人设提示词

在「人设与回复逻辑」中填入对应数字人的 System Prompt：

```
你是"灵若"，灵山胜境的AI数字人导游之一。
性格特点：温柔亲切、知性优雅，像一位贴心的姐姐。
说话风格：
- 用温暖、娓娓道来的语调讲述灵山的故事
- 善于将历史文化与现代生活联系起来
- 关注游客的感受，适时给予关怀
- 语速适中，温柔而有节奏感
- 称呼对方为"你"或"朋友"
你的任务：为游客提供人文讲解，推荐适合的游览路线，分享灵山的美学细节。

注意事项：
- 只回答与灵山胜境、旅游、文化相关的问题
- 对于不确定的信息，诚实说明并建议游客咨询景区工作人员
- 演出时间可能调整，提醒以当日公告为准
- 保持积极正面的态度
```

### 方式三：自建智能体服务

适合需要完全自定义的场景。

#### 核心代码结构

```javascript
// src/services/agentService.js
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.QWEN_API_KEY,
  baseURL: 'https://dashscope.aliyuncs.com/compatible-mode/v1'
});

// 人设提示词
const SYSTEM_PROMPTS = {
  lingruo: `你是"灵若"，灵山胜境的AI数字人导游...`,
  xiaoling: `你是"小灵"，灵山胜境的AI数字人导游...`,
  // ...
};

// 工具定义
const TOOLS = [
  {
    type: 'function',
    function: {
      name: 'search_knowledge',
      description: '在灵山景区知识库中检索相关信息',
      parameters: {
        type: 'object',
        properties: {
          query: { type: 'string' }
        },
        required: ['query']
      }
    }
  }
];

// 智能体调用函数
export async function callAgent(guideKey, messages, options = {}) {
  const response = await client.chat.completions.create({
    model: 'qwen-plus',
    messages: [
      { role: 'system', content: SYSTEM_PROMPTS[guideKey] },
      ...messages
    ],
    tools: TOOLS,
    temperature: 0.7,
    max_tokens: 800
  });

  return response.choices[0].message;
}
```

#### 工具执行逻辑

```javascript
// 工具调用结果处理
async function executeToolCall(toolCall) {
  const { name, arguments: args } = toolCall.function;
  const params = JSON.parse(args);

  switch (name) {
    case 'search_knowledge':
      // 调用 RAG 知识库检索
      return await searchKnowledgeBase(params.query);

    case 'get_weather':
      // 调用天气 API
      return await fetchWeather(params.location);

    case 'recommend_route':
      // 调用路线推荐引擎
      return recommendRoute(params);

    default:
      return { error: `未知工具: ${name}` };
  }
}
```

## 打卡照片合成功能

### 功能说明

用户打卡时上传现场照片，系统自动合成带有灵山主题的专属打卡照片。

### 技术实现

合成流程在浏览器端通过 HTML5 Canvas 完成，无需后端服务：

```
用户上传照片 → 加载背景配置 → Canvas 合成 → 生成 JPEG
```

合成层次：

```
┌─────────────────────────────┐
│  装饰边框                    │  ← drawDecorativeBorder()
├─────────────────────────────┤
│  前景文字（标题/时间/品牌）  │  ← drawForegroundElements()
├─────────────────────────────┤
│  用户照片（居中，圆角阴影）  │  ← drawUserPhoto()
├─────────────────────────────┤
│  背景装饰（图标/纹理）       │  ← drawBackgroundDecorations()
├─────────────────────────────┤
│  渐变背景                    │  ← drawGradientBackground()
└─────────────────────────────┘
```

### 核心代码

```javascript
// src/utils/photoSynthesizer.js
export async function synthesizeCheckinPhoto({
  userImage,
  background,
  width = 800,
  height = 1000
}) {
  const canvas = document.createElement("canvas");
  canvas.width = width;
  canvas.height = height;
  const ctx = canvas.getContext("2d");

  // 1. 绘制渐变背景
  drawGradientBackground(ctx, width, height, background.gradient);

  // 2. 绘制装饰元素
  drawBackgroundDecorations(ctx, width, height, background);

  // 3. 绘制用户照片
  const userImg = await loadImage(userImage);
  drawUserPhoto(ctx, userImg, width, height);

  // 4. 绘制前景文字
  drawForegroundElements(ctx, width, height, background);

  // 5. 绘制边框
  drawDecorativeBorder(ctx, width, height);

  return canvas.toDataURL("image/jpeg", 0.92);
}
```

## 常见问题

### Q: 不配置 API Key 能使用吗？

**可以。** 系统会自动回退到本地知识库模式，使用预设的 8 条关键词匹配问答。打卡照片合成功能不受影响，因为它在浏览器端本地处理。

### Q: API Key 放在前端安全吗？

**不推荐用于生产环境。** 建议：
- 演示/比赛环境：可以使用前端配置
- 正式部署：通过后端代理转发请求，API Key 放在服务端

### Q: 支持其他大模型吗？

**支持。** `agentConfig.js` 中的 API 配置兼容 OpenAI 格式，可以替换为：
- 通义千问（推荐）
- GPT-3.5/4
- 文心一言
- 智谱 GLM
- 其他 OpenAI 兼容接口

### Q: 如何添加更多打卡背景？

在 `src/data/checkinBackgrounds.js` 中添加新的背景配置：

```javascript
{
  id: "wuyin",
  title: "五印坛城 · 密藏寻踪",
  gradient: "linear-gradient(135deg, #4a2a1a 0%, #8a5a3a 100%)",
  overlayText: "五印坛城",
  overlaySubtext: "密藏寻踪 · 坛城之美",
  icon: "🕌"
}
```

### Q: 照片合成能否使用真实背景图片？

**可以。** 修改 `photoSynthesizer.js`，将 `drawGradientBackground` 替换为加载真实图片：


| 功能 | 实现方式 | Windows 可用性 |
|------|----------|---------------|
| 照片上传 | `<input type="file">` | ✅ 支持文件选择 |
| Canvas 合成 | 5 层叠加渲染 | ✅ 可用 |
| 照片下载 | `<a download>` | ✅ 可用 |
| 相机拍照 | `getUserMedia()` | ✅ 需浏览器权限 |
| 4 个打卡点 | 独立背景配置 | ✅ 全部可用 |
| 装扮系统 | 解锁机制 | ✅ 可用 |

> 💡 **注意**：Windows 桌面端拍照主要通过文件选择器上传图片。如果浏览器支持且设备有摄像头，也可以直接调用相机拍照。

### Windows 平台构建步骤

#### 环境准备

1. 安装 [Node.js 20.19+](https://nodejs.org/)
2. 安装 [Git](https://git-scm.com/)（可选）
3. 推荐使用 [Visual Studio Code](https://code.visualstudio.com/)

#### 构建命令（PowerShell）

```powershell
# 进入源码目录
cd "01_产品源代码\灵境智游源码"

# 安装依赖
npm install

# 配置 API Key（智能体模式必需）
# 编辑 .env.local 文件，填入 VITE_QWEN_API_KEY

# 构建生产版本
npm run build

# 更新 Windows 可执行程序的 www 目录
Remove-Item -Recurse -Force "..\..\02_Windows可执行程序\www"
Copy-Item -Recurse "dist" "..\..\02_Windows可执行程序\www"

# 验证
# 双击 ..\..\02_Windows可执行程序\灵境智游.exe
```

#### 构建命令（CMD）

```cmd
REM 进入源码目录
cd 01_产品源代码\灵境智游源码

REM 安装依赖
npm install

REM 构建生产版本
npm run build

REM 更新 Windows 目录（先删除旧的 www）
rmdir /s /q ..\..\02_Windows可执行程序\www
xcopy /e /i dist ..\..\02_Windows可执行程序\www
```

### Windows 平台常见问题

#### Q: exe 启动后浏览器没有自动打开

**解决方法**：
1. 检查控制台窗口是否显示访问地址（如 `http://127.0.0.1:4173/`）
2. 手动复制地址到浏览器地址栏
3. 确保默认浏览器已设置

#### Q: 智能体模式无法启用

**排查步骤**：
1. 确认 `.env.local` 中的 `VITE_QWEN_API_KEY` 已正确填写
2. 确认已重新执行 `npm run build` 并更新 `www` 目录
3. 打开浏览器开发者工具（F12），检查 Console 中是否有 API 错误
4. 检查 Network 面板中 API 请求是否返回 200

#### Q: 拍照打卡合成失败

**排查步骤**：
1. 确认照片格式为 JPG 或 PNG
2. 确认照片大小不超过 10MB
3. 更新浏览器到最新版本
4. 打开浏览器开发者工具检查错误信息

#### Q: C# 启动器如何重新编译

```powershell
# 使用 .NET Framework 自带编译器
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /out:灵境智游.exe /target:winexe scripts/Launcher.cs

# 或使用 .NET SDK（如已安装）
csc /out:灵境智游.exe /target:winexe scripts/Launcher.cs
```
