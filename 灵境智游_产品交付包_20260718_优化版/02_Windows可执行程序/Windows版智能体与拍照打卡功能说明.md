## 功能概述

Windows 版完整保留了 Web 版的全部功能，包括以下两大核心模块：

| 功能 | 说明 | 运行方式 |
|------|------|----------|
| **AI 智能体对话** | 基于通义千问大模型的数字人多轮对话 | 浏览器端调用云端 API |
| **拍照打卡** | 上传照片 + AI 合成专属打卡照 | 浏览器端本地 Canvas 处理 |

两个功能均在浏览器中运行，无需安装额外软件。Windows 可执行程序 `灵境智游.exe` 仅负责启动本地 Web 服务并打开浏览器。

## AI 智能体对话

### 功能简介

智能体（Agent）= 大语言模型 + 人设提示词 + 知识库 + 工具调用 + 记忆。

相比传统的关键词匹配问答，智能体具备以下能力：

- **语义理解**：不再局限于预设问题，能理解各种自然语言提问
- **多轮对话**：记住之前的对话内容，支持追问和上下文关联
- **人设表达**：每位数字人有独特的性格和说话风格
- **工具调用**：可实时查天气、推荐路线、查询演出时间
- **知识扩展**：通过 RAG 接入更多景区文档

### 五位数字人角色

| 角色 | 性格 | 适合人群 |
|------|------|----------|
| 🧒 **小灵** | 古灵精怪、活泼可爱 | 6-12 岁儿童 |
| 👩 **灵若** | 温柔亲切、知性优雅 | 普通游客 |
| 👨 **行远** | 沉稳可靠、学识渊博 | 深度文化爱好者 |
| 👴 **冬灵** | 和蔼慈祥、细心体贴 | 银发游客 |
| 👋 **外灵** | 开朗友好、国际视野 | 外籍游客 |

### 使用步骤

1. 启动 `灵境智游.exe`，等待浏览器自动打开
2. 在首页点击 **「AI 数字人问答」** 标签
3. 在左侧选择一位数字人导游
4. 在底部输入框中文字提问，或点击 🎤 麦克风按钮语音输入
5. 数字人会语音播报回答，同时在聊天气泡中显示文字

### 两种运行模式

系统会自动检测智能体 API 是否可用：

| 模式 | 条件 | 特点 |
|------|------|------|
| **🤖 智能体模式** | 已配置 API Key | 大模型驱动，语义理解，多轮对话 |
| **📚 本地知识库模式** | 未配置 API Key | 8 条预设问答，关键词匹配 |

未配置 API Key 时，系统自动回退到本地知识库模式，功能不受影响。

### 语音功能

Windows 版使用浏览器内置语音能力：

- **语音识别**（麦克风输入）：使用浏览器 Web Speech API，推荐 Edge 或 Chrome
- **语音合成**（数字人播报）：使用浏览器 `speechSynthesis`，调用系统可用语音

> 💡 **提示**：首次使用麦克风时，浏览器会弹出权限请求，请点击"允许"。

## 拍照打卡

### 功能简介

拍照打卡功能让游客在游览过程中完成 4 个打卡任务，每个任务会生成一张融合景区主题背景的专属照片。

### 四个打卡点

| 序号 | 打卡点 | 任务描述 |
|------|--------|----------|
| 01 | 灵山照壁 · 初见灵山 | 与「华夏第一壁」合影 |
| 02 | 九龙灌浴 · 花开见佛 | 上传现场照片 |
| 03 | 梵宫 · 穹顶寻光 | 找到穹顶飞天元素 |
| 04 | 灵山大佛 · 拥抱远方 | 抵达大佛平台 |

### 使用步骤

1. 点击首页 **「打卡与装扮」** 标签
2. 选择任意未完成的打卡点，点击 **「拍照打卡」** 按钮
3. 在弹出的文件选择器中选择一张照片（支持拍照上传或从相册选择）
4. 系统自动合成专属打卡照片（约 1-2 秒）
5. 合成完成后，在预览弹窗中可点击 **「保存照片」** 下载到本地

### 合成效果

打卡照片由以下层次合成：

```
┌─────────────────────────────┐
│  装饰边框 + 角落装饰          │
├─────────────────────────────┤
│  前景文字（标题/时间/品牌）    │
├─────────────────────────────┤
│  用户照片（居中、圆角、阴影）  │
├─────────────────────────────┤
│  背景装饰（图标/纹理）        │
├─────────────────────────────┤
│  渐变主题背景                 │
└─────────────────────────────┘
```

### 装扮系统

完成打卡任务可解锁数字人的新装扮：

| 装扮 | 解锁条件 |
|------|----------|
| 青玉常服 | 默认 |
| 莲华云肩 | 完成 2 个打卡点 |
| 佛光锦衣 | 完成全程 4 个打卡点 |
| 夜游华服 | 完成全程（隐藏成就） |

> 💡 **提示**：Windows 版拍照打卡完全在浏览器本地完成，不需要网络连接，照片不会上传到任何服务器。

## Windows 平台配置指南

### 方式一：直接使用（无需配置）

双击 `灵境智游.exe` 即可使用：
- 拍照打卡功能 **开箱即用**
- 智能体对话自动回退到 **本地知识库模式**

### 方式二：启用智能体模式

如需启用 AI 智能体对话，需要重新构建并配置 API Key：

#### 步骤 1：安装开发环境

1. 安装 [Node.js 20.19+](https://nodejs.org/)
2. 安装 [Visual Studio Code](https://code.visualstudio.com/)（推荐）

#### 步骤 2：配置 API Key

打开 `01_产品源代码/灵境智游源码/.env.local`，填入你的通义千问 API Key：

```env
VITE_QWEN_API_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VITE_QWEN_API_KEY=sk-你的API密钥
VITE_QWEN_MODEL=qwen-plus
```

> 📌 **获取 API Key**：访问 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，注册并创建 API Key。

#### 步骤 3：构建 Windows 版本

```powershell
# 进入源码目录
cd "01_产品源代码\灵境智游源码"

# 安装依赖
npm install

# 构建生产版本
npm run build

# 将构建产物复制到 Windows 目录
# 删除旧的 www 目录
Remove-Item -Recurse -Force "..\..\02_Windows可执行程序\www"
# 复制新的构建产物
Copy-Item -Recurse "dist" "..\..\02_Windows可执行程序\www"
```

#### 步骤 4：验证

1. 双击 `灵境智游.exe` 启动
2. 进入「AI 数字人问答」面板
3. 确认顶部显示 **🤖 智能体模式**（而非 📚 本地知识库）
4. 输入问题测试，如「灵山大佛有多高？」

### 方式三：使用其他大模型

`agentConfig.js` 中的 API 配置兼容 OpenAI 格式，可替换为其他大模型：

```env
# 通义千问（推荐）
VITE_QWEN_API_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# GPT-3.5/4（需替换 API Key）
VITE_QWEN_API_URL=https://api.openai.com/v1

# 智谱 GLM
VITE_QWEN_API_URL=https://open.bigmodel.cn/api/paas/v4

# 文心一言
VITE_QWEN_API_URL=https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop
```

## 重新构建 Windows 可执行程序

### 完整构建流程

```powershell
# 1. 进入源码目录
cd "01_产品源代码\灵境智游源码"

# 2. 安装依赖（首次）
npm install

# 3. 配置环境变量（如需智能体模式）
# 编辑 .env.local 文件

# 4. 构建生产版本
npm run build

# 5. 更新 Windows 版本的 www 目录
Remove-Item -Recurse -Force "..\..\02_Windows可执行程序\www"
Copy-Item -Recurse "dist" "..\..\02_Windows可执行程序\www"

# 6. 测试
# 双击 ..\..\02_Windows可执行程序\灵境智游.exe
```

### C# 启动器说明

Windows 可执行程序 `灵境智游.exe` 是一个 C# 编写的轻量级本地 Web 服务器：

- **源码位置**：`scripts/Launcher.cs`
- **功能**：启动本地 HTTP 服务 → 自动打开浏览器 → 提供静态文件服务
- **端口**：自动查找 4173-4190 范围内的可用端口
- **限制**：仅支持 GET 请求，不支持 POST API（智能体 API 直接从浏览器端调用，不经过此服务器）

如需重新编译 C# 启动器：

```powershell
# 使用 .NET SDK 编译
csc /out:灵境智游.exe /target:winexe scripts/Launcher.cs
```

## 常见问题与排查

### Q1：智能体模式显示「本地知识库」，如何切换？

**原因**：未配置 API Key 或 API Key 无效。

**解决方法**：
1. 检查 `.env.local` 文件是否存在且包含有效的 `VITE_QWEN_API_KEY`
2. 确认 API Key 未过期且有足够的额度
3. 重新执行 `npm run build` 并更新 `www` 目录

### Q2：麦克风无法使用

**原因**：浏览器未授权麦克风权限。

**解决方法**：
1. 点击浏览器地址栏左侧的 🔒 图标
2. 找到「麦克风」权限，设置为「允许」
3. 刷新页面重试
4. 推荐使用最新版 Microsoft Edge 或 Google Chrome

### Q3：拍照打卡上传照片后无反应

**可能原因**：
1. 照片格式不支持（建议使用 JPG/PNG）
2. 照片文件过大（建议小于 10MB）
3. 浏览器版本过旧

**解决方法**：
1. 将照片转换为 JPG 或 PNG 格式
2. 压缩照片大小后重试
3. 更新浏览器到最新版本

### Q4：语音播报没有声音

**可能原因**：
1. 系统音量为零或静音
2. 浏览器未安装中文语音包

**解决方法**：
1. 检查系统音量和扬声器
2. 在 Windows 设置 → 时间和语言 → 语言 中确认已安装中文语言包
3. 在 Windows 设置 → 辅助功能 → 文本转语音 中检查语音设置

### Q5：如何更换智能体模型？

修改 `.env.local` 中的配置：

```env
# 更换模型（可选值：qwen-turbo, qwen-plus, qwen-max）
VITE_QWEN_MODEL=qwen-max
```

修改后需要重新构建。

### Q6：Windows 版和手机版有什么区别？

| 特性 | Windows 版 | 手机 Web 版 |
|------|-----------|-------------|
| AI 智能体 | ✅ 相同 | ✅ 相同 |
| 拍照打卡 | ✅ 上传照片 | ✅ 可直接拍照 |
| 语音识别 | ✅ 浏览器支持 | ✅ 浏览器支持 |
| 语音播报 | ✅ 系统语音 | ✅ 系统语音 |
| GPS 定位 | ❌ 不支持 | ✅ 支持 |
| 离线使用 | ✅ 本地服务 | ❌ 需网络 |

### Q7：数据是否安全？

- **拍照打卡**：照片合成完全在浏览器本地完成，照片不会上传到任何服务器
- **智能体对话**：对话内容通过 HTTPS 加密传输到阿里云 API，不会保存到本地
- **个人信息**：用户画像数据保存在浏览器 `localStorage`，不会上传
