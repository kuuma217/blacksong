灵境智游 Windows 可执行版
=========================

一、快速启动
-----------
1. 双击"灵境智游.exe"。
2. 程序会自动启动本地站点并打开默认浏览器。
3. 默认从 4173 端口开始查找可用端口，最多尝试到 4190。
4. 请保持"灵境智游.exe"和"www"文件夹位于同一目录，不要单独移动 exe。
5. 关闭启动程序窗口即可停止本地服务。
6. 推荐使用最新版 Microsoft Edge 或 Google Chrome。

三、AI 智能体对话功能
-----------
本版本内置 AI 智能体对话功能，基于通义千问大模型：

  ▶ 两种运行模式：
    · 智能体模式（🤖）：需配置 API Key，支持语义理解、多轮对话、工具调用
    · 本地知识库模式（📚）：默认模式，无需配置，8 条预设问答

  ▶ 启用智能体模式：
    1. 在源码目录编辑 .env.local，填入通义千问 API Key
    2. 执行 npm run build 重新构建
    3. 将 dist 目录内容替换 www 目录
    4. 重启 灵境智游.exe

  ▶ 使用方式：
    · 进入「AI 数字人问答」面板
    · 选择数字人导游（小灵/灵若/行远/冬灵/外灵）
    · 文字输入或点击麦克风语音提问
    · 数字人自动语音播报回答

  ▶ 语音说明：
    · 语音识别需要允许浏览器使用麦克风（首次点击"允许"）
    · 语音合成使用浏览器内置语音，便携版自动回退到浏览器声线

四、拍照打卡功能
-----------
本版本内置拍照打卡功能，完全在浏览器本地处理：

  ▶ 4 个打卡点：
    01 灵山照壁 · 初见灵山
    02 九龙灌浴 · 花开见佛
    03 梵宫 · 穹顶寻光
    04 灵山大佛 · 拥抱远方

  ▶ 使用方式：
    · 进入「打卡与装扮」面板
    · 点击「拍照打卡」按钮
    · 选择照片上传（支持相机拍照或从文件选择）
    · AI 自动合成专属打卡照片（约 1-2 秒）
    · 可保存合成后的照片到本地

  ▶ 装扮系统：
    · 完成 2 个打卡点 → 解锁「莲华云肩」
    · 完成全部 4 个 → 解锁「佛光锦衣」和「夜游华服」

  ▶ 隐私说明：
    照片合成完全在浏览器本地完成，不会上传到任何服务器。

五、安全提醒
-----------
1. 如已配置 API Key 并重新构建，请注意 API Key 不要泄露。
2. 正式部署时，建议通过后端代理转发 API 请求，不要将 API Key 暴露在前端。
